# EasyTier 组网

EasyTier 负责让公网入口机和利群中转机互通。默认不使用公共节点，relay 会连接用户登记的 `cloud-entry`。

## 配置文件

网络配置：

```text
/etc/leikwan-wg-toolkit/easytier/network.env
```

字段：

```text
EASYTIER_NETWORK_NAME=<auto-generated>
EASYTIER_NETWORK_SECRET=<redacted>
EASYTIER_LISTEN_PORT=8301
EASYTIER_PROTOCOL=tcp
EASYTIER_RELAY_ET_IP=10.198.1.1
```

本项目默认 EasyTier 端口是 `8301/tcp`，位于利群推荐 `8000-9000` 白名单端口段。`11010` 只是 EasyTier 官方常见示例端口，不作为本项目默认值。

入口配置：

```text
/etc/leikwan-wg-toolkit/entries/entries.tsv
```

EasyTier 服务：

- `easytier-entry-<name>.service`
- `easytier-relay.service`

## 安装器

脚本会优先复用已安装的 `easytier-core` 和 `easytier-cli`。缺失时按以下顺序安装：

1. GitHub API release asset。
2. 确定性 Release URL。
3. `LEIKWAN_GITHUB_MIRRORS` 或 `LEIKWAN_GITHUB_MIRROR` 配置的镜像前缀轮询。
4. `/root/easytier*.tar.gz`、`/root/easytier*.zip` 或当前目录本地包。

脚本始终先尝试官方 GitHub 地址。镜像只作为下载慢或失败时的 fallback，不会硬编码依赖单个第三方代理。

示例：

```bash
export LEIKWAN_GITHUB_MIRRORS="https://mirror1.example/https://github.com,https://mirror2.example/https://github.com"
```

解包后通过 `find` 查找 `easytier-core` 和 `easytier-cli`，不假设目录结构。

## 验证

```bash
systemctl status easytier-relay --no-pager
systemctl status 'easytier-entry-*' --no-pager
easytier-cli peer
ip -br addr
ping 10.198.1.1
ping 10.198.1.2
```

如果 `easytier-cli peer` 能看到对端但 ping 暂时不通，doctor 会给 WARN，便于继续排查安全组、系统路由或 EasyTier 参数。
