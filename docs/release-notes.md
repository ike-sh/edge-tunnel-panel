# Release Notes

## 1.4.0 LTS

1.4.0 LTS 是 Leikwan Toolkit 的功能冻结版。

项目定位收敛为：

```text
A 公网入口 + B 中转主机 + C 后端目标 的 TCP/UDP 转发组网工具
```

本版重点：

- 主菜单收敛为 6 个核心入口。
- 普通用户路径压缩为“快速组网、B、A、DDNS、状态 / 诊断、高级维护”。
- `lq status` 默认输出更短的最终版状态。
- 高级、低频和高危操作移动到“高级维护”。
- README 重写为最终用户视角，详细命令移到 docs。
- 保留既有 CLI 兼容，不删除旧用户脚本依赖的命令。

后续版本主要只做：

- bug fix
- 兼容性修复
- 安全修复
- 文档完善
