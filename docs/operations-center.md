# 状态 / 诊断与高级维护

1.4.0 LTS 起，原“运维命令中心”不再作为主菜单入口展示，常用运维能力已经合并到两个更清楚的菜单：

```text
5. 状态 / 诊断
6. 高级维护
```

## 状态 / 诊断

```text
1. 状态总览
2. 简洁状态
3. 一键诊断
4. 自动修复常见问题
5. 端口冲突检查
6. 查看日志
0. 返回
```

这里放日常巡检和故障处理。

## 高级维护

```text
1. EasyTier 服务管理
2. 配置备份 / 快照 / 回滚
3. 配置导入 / 导出
4. 自更新
5. 端点输出
6. 调试报告
7. 卸载
0. 返回
```

这里放低频、高危或专业操作。高危操作继续保留确认、快照和并发锁保护。
