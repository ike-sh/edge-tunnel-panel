# 拓扑说明

## 单节点直接转发

```text
客户端 -> 公网入口节点 -> 本机或局域网目标服务
```

适合目标服务就在入口节点上，或入口节点能够直接访问目标地址。

## 双节点隧道转发

```text
外部客户端
-> A 公网入口节点
-> EasyTier
-> B 落地执行节点
-> 落地服务器 IP/域名:端口
```

适合 B 节点没有公网 IPv4，只能主动接入主控和 EasyTier overlay。

## v0.2.8-test 推荐流程

1. 在“节点”页添加两个 Agent。
2. 在“组网配置”页使用“快速组网”。
3. 选择 A 公网入口节点和 B 落地执行节点。
4. 面板自动给 A 下发 listeners，peers 为空。
5. 面板自动给 B 下发 listeners 和指向 A 公网 IP 的 peers。
6. 系统在约 20 秒后自动验证 Peer、延迟、丢包、隧道和路由。
7. 进入“转发规则”，填写公网监听端口、落地服务器地址和落地端口。

## 组网成功判断

- 两个节点 EasyTier service 均为运行中。
- 至少一侧发现远端 Peer。
- 延迟和丢包可读。
- 路由为 `DIRECT` 或可用路径。
