# 拓扑说明

## 单节点直接转发

```text
客户端 -> 公网入口节点 -> 本机或局域网目标服务
```

适合目标服务就在入口节点上，或入口节点能够直接访问目标地址。

## 多节点隧道转发

```text
客户端 -> 公网入口节点 -> EasyTier overlay -> 后端节点 -> 目标服务
```

适合后端节点没有公网 IPv4，只能主动接入主控和 overlay 网络。

## v0.2.5-test 推荐流程

1. 在“节点”页添加两个 Agent。
2. 在“组网配置”页使用“快速组网”。
3. 选择公网入口节点和后端节点。
4. 面板自动给入口节点下发 listeners，peers 为空。
5. 面板自动给后端节点下发 listeners 和指向入口公网 IP 的 peers。
6. EasyTier service 启动后，使用“验证组网”检查 Peer、延迟、丢包、隧道和路由。
7. 后端节点获得虚拟 IP 后，可以创建转发规则。

## 组网成功判断

- 两个节点 EasyTier service 均为运行中。
- 至少一侧发现远端 Peer。
- 延迟和丢包可读。
- 路由为 `DIRECT` 或可用路径。
- 后端节点最好有 EasyTier 虚拟 IP，便于转发规则使用。
